# 逃げろ工科トン

## 実行環境の必要条件
* python >= 3.10
* pygame >= 2.1
* 必要なものがあれば追記してください（非推奨）

## ゲームの概要
* 迫ってくる天井から常に逃げ続けろ！
* 参考URL：[サイトタイトル](https://www.4gamer.net/games/560/G056032/20210322001/)

## ゲームの遊び方
* 左右の矢印キーを使って迫ってくる天井を避け続ける
* 潰れたらゲームオーバー
## ゲームの実装

### 共通基本機能
* 背景画像と主人公キャラクターの描画

### 分担追加機能
* アイテムシステム（担当：孫 鵬斐 ）
    ゲーム中にランダムでアイテムが出現する機能を実装した。
    赤色アイテムを取得するとHPが10回復する。
    黄色アイテムを取得すると3秒間無敵状態になる。
    緑色アイテムを取得すると5秒間移動速度が上昇する。
    紫色アイテムを取得すると5秒間こうかとんが小さくなる。
